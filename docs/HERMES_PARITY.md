# Hermes parity roadmap

Nexora is implementing the useful architecture patterns independently while keeping its own local-first policy.

## Parity surface

- Persistent memory and session search
- Tool registry/toolsets
- Progressive-loading skills with approval
- Terminal/file tools behind explicit policy
- Browser automation adapter
- Vision/image input adapter
- TTS/STT/voice session adapters
- Wake-word adapter on supported devices
- Subagent delegation with isolated context
- Cron/scheduled jobs
- Event hooks and audit log
- Batch/evaluation runner
- MCP client registry
- OpenAI-compatible API
- CLI/TUI
- Web dashboard
- Telegram and WhatsApp channels
- Profiles and SOUL.md personality
- Android mobile companion

Nexora will not copy Hermes source code; these capabilities will be implemented as independent adapters.
